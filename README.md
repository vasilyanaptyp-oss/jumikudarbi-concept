An unsolicited, unofficial homepage concept prepared by Artur Vasilyan for JumiķuDarbi.lv on 27 September 2026. Public company details and photos are from [jumikudarbi.lv](https://jumikudarbi.lv/). This is a design proposal, not the company's official website.
